## ✨ 关于我们

「晓欢故事」是一个记录生活思考与感悟的小站。

我们相信，生活的智慧往往藏在琐碎的日常里。在这里，我们写下那些被忽略的瞬间、被遗忘的情绪，以及那些从复杂人生中慢慢沉淀下来的简单道理。

每一篇文章都同步发布在公众号「晓欢故事」，欢迎关注，一起在文字里找到生活的温度。

## 📖 我们在写什么

- **生活琐事** — 那些微小却真实的日常片段
- **散文笔记** — 对生活的思考与有感而发
- **简单生活** — 从复杂走向简单的人生体悟

## 🚀 关于本站

本组织下的个人小站由 **GitHub Pages** 驱动，页面风格简洁克制，专注于内容本身。
